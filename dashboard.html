Input Pembayaran Siswa

-- Pilih Siswa terlebih dahulu --
Centang jenis pembayaran yang akan dilunasi. Nominal dapat diubah untuk bayar sebagian.
Terisi otomatis dari tarif, bisa diubah bila perlu (mis. bayar sebagian).

Input Transaksi Tabungan

Impor Transaksi Siswa (CSV)

Unggah file CSV dengan pemisah koma (,). Baris pertama wajib berisi header dengan susunan kolom:
NISN, Nama, Kelas, Pembayaran, Nominal
Sistem otomatis menolak baris jika NISN dan Jenis Pembayaran sudah pernah dicatat sebelumnya.

Menyiapkan data...

Impor Transaksi Internal (CSV)

Unggah file CSV dengan pemisah koma (,). Baris pertama wajib berisi header dengan susunan kolom:
Jenis, Keterangan, Nominal
(Jenis: Pemasukan / Pengeluaran)
Sistem otomatis menolak baris jika Keterangan dan Nominal persis sama dengan yang sudah ada.

Menyiapkan data...

Impor Tarif Pembayaran (CSV)

Unggah file CSV dengan pemisah koma (,). Baris pertama wajib berisi header dengan susunan kolom:
Nama Pembayaran, Target Kelas, Nominal Tarif
Sistem otomatis menolak baris jika Nama Pembayaran persis sama dengan yang sudah ada.

Menyiapkan data...
